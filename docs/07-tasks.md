- [ ] Создать Angular-проект, подключить Angular Material.
- [ ] Поставить FullCalendar v7 (`@fullcalendar/angular@7`, `fullcalendar@7`, `temporal-polyfill`).
- [ ] Проверка 1: вертикальная прокрутка по месяцам (multi-month).
- [ ] Проверка 2: перетаскивание события через границу месяца.
- [ ] Проверка 3: кастомная карточка события (иконка + цветные теги).
- [ ] Записать результаты и принять решение по запасному плану.
- [ ] Создать Nest-проект, Docker Compose с Postgres, подключить Prisma.

- [ ] Навигация (кнопки, «Сегодня»).

- [ ] Drag-and-drop и ресайз.

- [ ] Удаление с отменой.

- [ ] Автосоздание личного календаря.
- [ ] Сервис доступа и guard на все эндпоинты.
- [ ] `GET /auth/me`, выход.
- [ ] Переключатель календарей, цвет календаря.
