# Notion-style календарь: обзор

Статус на 2026-10-09: планирование, код ещё не начат.

## Цель

Веб-календарь в духе Notion для личного использования. Основной пользователь: девушка автора, она же заказчик. Календарь должен быстро стать рабочим, а попутно автор осваивает новый стек (NestJS, Prisma, OAuth, Docker).

## Принципы

- Сначала рабочий календарь, потом всё остальное. Первую версию можно показать заказчику как можно раньше.
- Готовое берём там, где учиться нечему (сетка календаря), своё пишем там, где обучение (бэкенд, авторизация, теги, диалоги).
- Хранилище и источник иконок прячем за интерфейсами, чтобы менять их без переписывания компонентов.
- ИИ-агент добавляем только когда основа готова.

## Ключевые решения

| Вопрос                             | Решение                                                                                           | Почему                                                                          |
| ---------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Календарь                          | FullCalendar v7 (`@fullcalendar/angular`)                                                         | Многодневные события, drag-and-drop и ресайз уже есть. Писать свою сетку дольше |
| UI-кит                             | Angular Material                                                                                  | Выбор автора                                                                    |
| Бэкенд                             | NestJS + Prisma                                                                                   | Похож на Angular по устройству, автор хочет освоить                             |
| БД                                 | PostgreSQL (Docker)                                                                               | Стандарт, потом можно добавить `pgvector`                                       |
| Вход                               | Только Google, без паролей                                                                        | Проще и безопаснее                                                              |
| Календари                          | Несколько календарей на пользователя, с участниками (схема готова сразу, интерфейс шаринга позже) | Личный, с коллегами, с второй половиной                                         |
| Иконки                             | Встроенный набор + эмодзи + ссылка по URL. Загрузки файлов нет                                    | Не грузит БД, проще                                                             |
| Повторяющиеся события              | Да, через `rrule`                                                                                 | Нужны заказчику                                                                 |
| Темы                               | Светлая и тёмная                                                                                  |                                                                                 |
| Языки                              | ru, es, en. Сначала только ru, но i18n закладываем с начала                                       |                                                                                 |
| Телефон                            | Использование редкое, делаем адаптивный вид позже                                                 |                                                                                 |
| Ограничение доступа (список email) | Перед выкладкой в прод, локально не нужно                                                         |                                                                                 |
| ИИ-агент                           | После готовой основы. Сначала tool calling, RAG только если появятся заметки                      |                                                                                 |
