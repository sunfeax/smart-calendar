# Функции

Приоритеты: **MVP** (первая рабочая версия), **v1** (до выкладки в прод), **позже**.

## Календарь (MVP)

- [ ] Месячный вид на весь экран (4–6 недель), ячейки растягиваются по высоте.
- [ ] Перелистывание месяцев кнопками и прокрутка вниз (вариант прокрутки зависит от проверки FullCalendar, см. `04-calendar-frontend.md`).
- [ ] Кнопка «+» на каждой дате: открывает диалог создания события с этой датой.
- [ ] Клик по событию: открывает диалог редактирования.
- [ ] Многодневные события (полосы через несколько дней).
- [ ] Drag-and-drop события на другую дату и ресайз границ.
- [ ] Перенос на далёкую дату через выбор даты в диалоге.
- [ ] Кнопка «Сегодня», подсветка текущего дня.
- [ ] Неделя начинается с понедельника.

## События (MVP)

- [ ] Название, описание, дата начала и окончания, весь день.
- [ ] Дедлайн (отдельное поле, смысл уточнить: `08-open-questions.md`).
- [ ] Иконка события: встроенный набор, эмодзи или ссылка `https://…`.
- [ ] Теги по категориям (см. ниже).
- [ ] Удаление с возможностью отмены (мягкое удаление + «Отменить» в уведомлении).

## Теги и категории (MVP)

- [ ] Пользователь создаёт сколько угодно категорий («Платформа», «Приоритет», «Клиент»…).
- [ ] В каждой категории свои теги.
- [ ] Цвет тега из палитры (ключ палитры, не hex, чтобы работала тёмная тема).
- [ ] Категория может быть «один тег» или «несколько тегов».
- [ ] Теги отображаются на карточке события.
- [ ] Фильтр событий по тегам (v1).

## Несколько календарей

- [ ] У пользователя при первом входе автоматически создаётся личный календарь (MVP).
- [ ] Создание, переименование, цвет и удаление календарей (MVP).
- [ ] Переключение и показ нескольких календарей одновременно (v1).
- [ ] Участники календаря и роли (владелец, редактор, наблюдатель). Схема БД готова с самого начала, интерфейс приглашений позже.
- [ ] Приглашение по email или ссылке (позже).

## Повторяющиеся события (v1)

- [ ] Правило повтора (ежедневно, еженедельно, ежемесячно, по дням недели, до даты или N раз).
- [ ] Удаление всей серии.
- [ ] Пропуск одного повторения.
- [ ] Редактирование одного повторения (позже).

## Вход и доступ

- [ ] Вход только через Google (MVP).
- [ ] Данные пользователей изолированы через членство в календарях (MVP).
- [ ] Список разрешённых email, чтобы не мог войти любой аккаунт Google (v1, перед выкладкой в прод).

## Внешний вид

- [ ] Светлая и тёмная тема, переключатель и автоопределение (v1).
- [ ] Интерфейс на русском (MVP), переводы закладываем с начала. Испанский и английский (v1 или позже).
- [ ] Адаптация под телефон: на узких экранах список вместо сетки (v1, использование редкое).
- [ ] PWA (иконка на экране) (позже).
