# Календарь на фронтенде (FullCalendar v7)

Решение принято: берём FullCalendar v7, проверка пройдена (см. ниже). Утверждения об API основаны на документации v7, проверенной частично. Всё помеченное «проверить» нужно сверить с доками v7.

## Требования и как их закрыть

| Требование                          | План                                                                          |
| ----------------------------------- | ----------------------------------------------------------------------------- |
| Месяц на весь экран (4–6 недель)    | Вид месяца, высота 100% контейнера                                            |
| Перелистывание кнопками             | Встроенная навигация или свои кнопки + API календаря                          |
| Прокрутка вниз по месяцам           | Multi-month вид в один столбец                                                |
| Кнопка «+» на дате                  | Шаблон содержимого ячейки дня (проверить в v7)                                |
| Диалог по клику на дату и событие   | Колбэки клика по дате и событию, внутри открываем Material-диалог             |
| Drag-and-drop и ресайз              | Включается опциями. Колбэки переноса и ресайза отправляют изменения на сервер |
| Многодневные события                | Встроенная раскладка полос                                                    |
| Карточка события с иконкой и тегами | Шаблон содержимого события (`eventContent`)                                   |
| Тёмная тема                         | Тёмные варианты тем v7                                                        |
| Русская локаль                      | Локаль FullCalendar + понедельник первым днём                                 |

## Проверка до старта (spike, 2–3 часа)

Создать пустой Angular-проект, поставить FullCalendar v7 и проверить три вещи.

1. **Прокрутка по месяцам.** Есть ли multi-month вид, где месяцы идут один за другим вертикально, каждый месяц целиком, и ведёт ли он себя как нужно (высота, подгрузка, «щелчок» к началу месяца через `scroll-snap`).
2. **Перетаскивание через границу месяца.** Прокручивается ли календарь сам, когда событие тянут к краю. Если нет, нужен запасной вариант.
3. **Кастомная карточка события.** Получается ли вставить иконку и цветные теги шаблоном и стилизовать под Notion.

**Результат (2026-10-10):** все три проверки пройдены, FullCalendar подходит. Запасной план не нужен.

## Работа с данными

- Компонент календаря не знает про HTTP. Он работает с сервисом-API событий (`list`, `create`, `update`, `delete`), который возвращает Observable.
- События загружаются за видимый диапазон: колбэк смены дат календаря записывает диапазон в signal, а `rxResource` с этим signal в `params` перезапрашивает события и отменяет устаревший запрос (стандарт в `01-stack.md`).
- **Оптимистичные обновления**: при переносе и ресайзе событие сразу встаёт на новое место, запрос идёт в фоне. При ошибке откат через `revert()` и сообщение пользователю.
- Для событий «на весь день» помнить, что конец эксклюзивный.

## Диалог события (Angular Material)

- Поля: название, описание, начало, окончание, весь день, выполнено, иконка, теги по категориям, повтор.
- Выбор даты через Material datepicker, он же основной способ переноса на далёкую дату.
- Выбор иконки: вкладки «Набор», «Эмодзи», «Ссылка».
- На мобильных диалог на весь экран.

## Внешний вид

- Тема FullCalendar v7 подбирается под Material (или переопределяется CSS-переменными).
- Карточка события нейтральная серая, без своего цвета. Цвет несут иконка и теги внутри карточки. Серый берётся из токенов темы, чтобы работал в светлой и тёмной теме.
- Тёмная тема: переключается вместе с темой Material и темой FullCalendar.

## Телефон

- Использование редкое, поэтому отдельный адаптивный вид делаем после основных функций.
- На узких экранах: вид списка (agenda) вместо сетки, кнопка создания события, диалог на весь экран.
